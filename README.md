# 🚀 Kanban Board

A modern, responsive Kanban task management application built with **React JS**. Organize tasks, manage priorities, track progress, and stay productive with a clean and interactive dashboard.

## ✨ Features

- **Task Management:** Create, edit, and delete tasks.
- **Drag and Drop:** Move tasks between different columns.
- **Three Workflow Columns:** To Do, In Progress, and Done.
- **Priority Management:** Assign High, Medium, and Low priorities.
- **Task Details:** View detailed task information.
- **Context API:** Manage application-wide task state.
- **Local Storage:** Automatically save tasks in the browser.
- **Reminders:** Set task reminders with browser notifications.
- **Dark and Light Mode:** Switch between two themes.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd kanban-board
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit `http://localhost:5173/` in your browser.
